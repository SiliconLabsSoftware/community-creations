# Silicon Labs IoT Utilities Applications #

Silicon Labs has shared a variety of [IoT Utilities Applications Examples](https://github.com/SiliconLabsSoftware/iot_utilities_applications) to help you get started. By sharing your own ideas and projects, you’ll not only add to the creativity of the community—you’ll also inspire and support others who are exploring similar paths.

This repo is all about community collaboration—whether you're a developer, hobbyist, or enthusiast, you're welcome to share your own IoT Utilities projects, contribute ideas, and learn from others. This page lists projects as links to external GitHub repositories.

## Requirements ##

1. Silicon Labs EFR32/SiWx Development Kit
2. Simplicity Studio 5, Simplicity Studio 6, external tool compatibility, standalone version
3. Compatible SDK version, you can install it via Simplicity Studio or download it from our GitHub [Simplicity SDK](https://github.com/SiliconLabsSoftware/sisdk-release)
4. Compatible Third-Party Hardware Drivers extension as specified in each project's readme file, available [here](https://github.com/SiliconLabs/third_party_hw_drivers_extension)

## How to contribute ##

This repository accepts link submissions (not project source code). To share your project, add a new row to the table below with:

- a link to your public GitHub repository
- a 1-2 sentence description
- a link to your GitHub profile
- append your new row to the bottom of the table (do not reorder or edit existing rows)

See [How to Contribute](../../../README.md#how-to-contribute) and [CONTRIBUTING.md](../../../.github/CONTRIBUTING.md) for details.
