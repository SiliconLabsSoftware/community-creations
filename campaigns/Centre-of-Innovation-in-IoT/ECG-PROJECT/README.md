Smart Heart Sound Monitoring System Using Adaptive Notch Filtering and Bluetooth Connectivity is an IoT-based healthcare solution that filters noise from heart sound (PCG) signals using an adaptive notch filter and transmits the processed data via Bluetooth for real-time monitoring and analysis.
